# QUADRA — باشگاه پدل

وب‌اپ موبایل‌محور (PWA) برای باشگاه پدل **کوادرا** با **۴ زمین** — فقط پدل، فقط یک باشگاه.
دو ورودی جدا دارد: **بازیکن** (اپ موبایل) و **مدیر باشگاه** (داشبورد دسکتاپ).

## اجرا
```bash
npm install
npm run dev      # توسعه
npm run build    # خروجی در dist/
```
ورود مدیر (نسخه‌ی نمایشی): نام کاربری `admin` · رمز `quadra`

## بازیکن
- **موشن استینگ** ورود: کشیده شدن قاب لوگو، ورود «۴» فیروزه‌ای با رد نور، و چهار خط به نشانه‌ی ۴ زمین.
- **عضویت**: موبایل → کد تأیید (شبیه‌سازی) → نام → تعیین سطح (۹ سطح A تا D یا آزمون ۳ سؤالی).
- **ویزارد ساده** (دکمه‌ی +): رزرو زمین · پیدا کردن مچ · کلاس با مربی · تورنمنت
  - ماتریس «ساعت × ۴ زمین» با قیمت هر نفر و ساعت‌های پیک
  - چیدمان ۴ بازیکن روی زمین، دعوت دوست و «بازی باز» برای پر کردن جای خالی با هم‌سطح‌ها
  - پرداخت با کیف پول، اعتبار پکیج یا کارت (شبیه‌سازی درگاه)
- **پکیج‌ها**: ۵ و ۱۰ سانس، عضویت طلایی و بلک (تخفیف + XP دوبرابر)؛ پکیج‌های مربی (تک، ۴، ۸ جلسه، گروهی).
- **فروشگاه پدل**: راکت، کفش، لباس رسمی باشگاه، توپ، ساک و لوازم جانبی؛ جستجو، دسته، فیلتر برند/قیمت/جنسیت/موجودی/تخفیف، مرتب‌سازی، رنگ و سایز، سبد خرید و تحویل در پذیرش.
- **گیمیفیکیشن**: XP و ۶ رتبه (برنز تا افسانه)، ۱۱ نشان، چالش‌های هفتگی، استریک هفتگی، رنکینگ باشگاه با سکو، کانفتی، صدا و لرزش، درخواست‌های پیوستن زنده.

## مدیر
نمای کلی (KPI، درآمد ۳۰ روز به تفکیک منبع، ترکیب درآمد، روش‌های پرداخت، نقشه‌ی اشغال روز×ساعت، تایم‌لاین امروز، موارد نیازمند اقدام، آخرین تراکنش‌ها) ·
تقویم ۴ زمین با رزرو دستی، تسویه، لغو/استرداد و انتقال بین زمین‌ها · جدول رزروها · پرداخت‌ها (معوق، پیش‌رو، مسترد، خروجی CSV) ·
فروشگاه (سفارش‌ها به‌شکل کانبان، موجودی انبار، پرفروش‌ها) · مربی‌ها و فروش پکیج · اعضا با بخش‌بندی · تنظیمات نرخ پیک/عادی و وضعیت زمین‌ها.

داده‌ها بین اپ بازیکن و پنل مدیر مشترک‌اند (حتی در دو تب مرورگر): رزروی که بازیکن می‌زند فوراً در تقویم مدیر دیده می‌شود.

## یادداشت‌ها
- این نسخه فرانت‌اند است؛ داده‌ها ساختگی‌اند (`src/data.js`) و در `localStorage` ذخیره می‌شوند. برای نسخه‌ی واقعی بک‌اند، درگاه پرداخت و پیامک لازم است.

- تصاویر: Unsplash و Wikimedia Commons — فهرست مجوزها در `src/data.js` (`CREDITS`) و صفحه‌ی پروفایل.
